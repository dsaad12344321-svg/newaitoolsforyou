# AI Tools Hub

دليل عربي لاكتشاف أدوات الذكاء الاصطناعي والبحث عنها.

## المميزات الحالية

- واجهة عربية كاملة باتجاه RTL.
- بحث مباشر باسم الأداة أو وصفها أو كلماتها المفتاحية.
- تصفية الأدوات حسب التصنيف.
- بطاقات مستقلة لكل أداة مع وصف ورابط مباشر.
- تصميم متجاوب للهواتف والأجهزة اللوحية والكمبيوتر.
- إضافة أدوات جديدة من مصفوفة البيانات داخل `app/page.tsx`.

## الأدوات المضافة

- [NotebookLM](https://notebook.google.com/)
- [AI Free Forever](https://aifreeforever.com/)
- [VoiceStudio](https://voicestudio.sh/)
- [Muapi](https://muapi.ai/)

## التشغيل محلياً

يتطلب Node.js 20 أو إصداراً أحدث.

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## النشر على Vercel

اربط هذا المستودع بحساب Vercel، واختر Next.js كإطار العمل. أوامر البناء الافتراضية هي `npm run build` ومجلد الإخراج الافتراضي الخاص بـ Next.js.

## إضافة أداة جديدة

أضف عنصراً جديداً إلى مصفوفة `tools` في `app/page.tsx` مع الاسم والوصف والتصنيف والرابط والكلمات المفتاحية.
